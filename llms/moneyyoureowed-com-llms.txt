# Money You're Owed

> Plain-English US consumer money-recovery help: free official-route checklists and one-time-purchase self-help kits (deposits, refunds, denied claims, unclaimed property). Publishes two free, anonymous, read-only agent surfaces over the same fact catalog: a remote MCP server and an A2A 1.0 agent.

Generated by API Evangelist on 2026-09-19 from the provider's public surface (the provider publishes no llms.txt of its own — /llms.txt returned 404 on all four hosts).

## Agent surfaces

- [Connect your AI assistant](https://moneyyoureowed.com/connect): the only human page for the machine surfaces; documents the MCP endpoint, no-auth posture and rate limiting.
- [MCP endpoint](https://mcp.moneyyoureowed.com/mcp): Streamable HTTP, protocol 2025-06-18, one tool `answer_money_question` (question: string). Anonymous. POST only.
- [A2A Agent Card](https://agent.moneyyoureowed.com/.well-known/agent-card.json): A2A 1.0, JSONRPC binding at https://agent.moneyyoureowed.com (method `SendMessage`), skill `answer-money-questions`. Anonymous.
